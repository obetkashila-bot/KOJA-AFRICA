KOJA APK — QUICK START FROM ANDROID

1. Open GitHub repository KOJA-AFRICA.
2. Open Actions.
3. Select "KOJA AFRICA Android APK Build".
4. If the workflow is not listed yet, commit this package to main/master first.
5. Open the successful workflow run.
6. Scroll to Artifacts.
7. Tap "koja-africa-production-apk".
8. Download the artifact ZIP.
9. Extract it and install app-debug.apk.

Do not choose the generic GitHub "Android CI" template. Use the KOJA workflow included in this package.
