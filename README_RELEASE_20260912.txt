KOJA AFRICA — DOWNLOADABLE APP RELEASE PACKAGE

This package is the consolidated cross-platform release foundation for the existing KOJA production service.

Production backend remains:
https://koja-africa.onrender.com

Application ID:
com.kojaafrica.app

Platforms:
Android
iOS
Windows
macOS
Linux
Web/PWA

Android/iOS use Capacitor.
Desktop uses Electron + electron-builder.

The package is configured for release generation, but store signing cannot be performed inside this package because Google Play and Apple signing certificates belong to the publisher account.

No Render service move is required. Keep KOJA-AFRICA in the existing Render Production service.
