KOJA NEXUS AFRICA NOW — JOBS UPDATE

Version: 2.1-jobs

AFRICA NOW now collects job opportunities alongside news.

Sources:
- African Development Bank official vacancies RSS endpoint
- AfriCareers job listings
- ZambiaJobsToday job listings

Jobs are refreshed with the same AFRICA NOW 5-minute cycle, deduplicated by URL, and displayed as "Jobs & Opportunities" items with a direct link to the original vacancy.

The collector is best-effort and preserves previously saved stories/jobs if a source temporarily fails. Render free services can sleep, so a sleeping instance cannot perform background refreshes until it receives a request again.
