KOJA NEWS STUDIO ASSETS FIX

This update connects uploaded Supabase Storage backgrounds and desks to KOJA NEWS Live.

1. Run KOJA_NEWS_STUDIO_ASSETS_FIX.sql in Supabase SQL Editor.
2. Deploy app.py.
3. Open /admin/news/studio-assets.
4. Upload backgrounds and transparent desk PNGs.
5. Open /admin/news/live.
6. Select the background and desk, then GO LIVE / UPDATE STUDIO.
7. Open /news/live.

No Cloudflare and no KOJA NODE are included. Existing HLS source handling remains unchanged.
