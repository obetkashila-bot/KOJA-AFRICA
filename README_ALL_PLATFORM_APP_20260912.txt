KOJA ALL-PLATFORM APP FOUNDATION

Added to the current KOJA production Flask application:
- installable PWA manifest
- KOJA application icons
- service worker and offline shell/cache fallback
- mobile web-app metadata
- Apple home-screen metadata
- /manifest.json endpoint
- /service-worker.js endpoint
- foundation for Android, iOS, Windows, macOS and Linux wrappers

This package does not replace Render Production and does not alter Supabase data.
The native store signing/submission steps still require platform developer accounts and platform-specific build environments.
