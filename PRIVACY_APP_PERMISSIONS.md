# KOJA AFRICA App Permissions

KOJA may request notifications, camera, microphone, photo/file access and location only when a feature requires them.

Location is used for delivery and live location features.
Camera and microphone are used for communication, media and supported services.
Notifications are used for messages, calls, orders, deliveries and important account events.
Files and photos are used when the user chooses to upload or share content.

Platform store permission text must be reviewed before publication and must match the actual features enabled in production.
