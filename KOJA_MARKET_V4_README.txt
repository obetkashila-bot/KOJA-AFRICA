KOJA AFRICA — KOJA MARKET V4 + KOJA BUSINESS

Built on V52 and V3. Preserves existing KOJA services and Communications.

V4 adds commerce integration and production workflows: Market-to-Business sales/inventory synchronization, payment verification ledgering, delivery-job creation, seller payouts, coupons, advertising event counters, commercial admin controls, and complete Business operational pages for customers, suppliers, invoices, employees/payroll, online store, AI assistant, payments and delivery.

Deploy: use app.py with the existing Render start command. Run KOJA_MARKET_V4.sql after the earlier KOJA_MARKET SQL files. Configure the licensed payment provider keys already used by KOJA. Never expose provider secret keys to the browser.
